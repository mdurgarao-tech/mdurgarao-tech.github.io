What I do

I'm a WAF and application security engineer with 6+ years of experience protecting enterprise web applications and APIs, including 4 years hands-on with Imperva WAF. My focus is WAF policy design, managed and custom rule tuning, OWASP Top 10 protection, bot mitigation, rate limiting and API security across Imperva, Akamai, AWS WAF, Azure WAF, Cloudflare and FortiWeb.

That web-layer work sits on solid network security depth: Zscaler Zero Trust (ZIA/ZPA), Palo Alto, Fortinet, Check Point, Cisco ASA and F5 LTM. I've run WAF onboarding and tuning on Imperva and AWS WAF, executed managed ruleset upgrades, conducted cloud-native WAF audits for Azure-hosted apps, cleaned up 2,000+ firewall rules using FireMon, and handled incidents and changes in ITIL-driven operations.

Based in Hyderabad, open to WAF, application security, cloud security and network security roles — remote or hybrid.
