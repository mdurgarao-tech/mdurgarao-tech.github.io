Professional Summary

I'm a WAF and Application Security Engineer focused on protecting enterprise web applications and APIs at the application layer. My core work is WAF policy design and rule tuning, OWASP Top 10 protection, API onboarding and protection, bot mitigation, rate limiting, and — the part that matters most — false-positive reduction, so protection stays strong without blocking legitimate traffic.

WAF Case Study

Reducing WAF False Positives Without Weakening Protection

Context
After onboarding a web application to a WAF, a managed SQL-injection ruleset began firing repeatedly on a free-text field, blocking legitimate user submissions.
Problem
Legitimate prose containing SQL-like words (e.g. "the SELECT dropdown doesn't update the table") triggered the rule — a false positive that risked blocking real users at scale.
Approach
Kept the rule in detection mode first, baselined the field's normal traffic, and investigated the blocked-traffic log to confirm the hits were customers, not attackers.
Implementation
Scoped a narrow exception to the specific parameter on the specific route — leaving SQLi enforcement fully active on every other parameter, including login and search — then moved to staged enforcement.
Result
False positives on that parameter dropped to zero with no reduction in protection coverage elsewhere; the exception was documented so the reasoning is clear to the next engineer.
Tools
WAF managed rulesets, detection/blocking enforcement modes, WAF log analysis.
